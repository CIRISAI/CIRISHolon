# Trademark policy

"CIRISHolon", "CIRIS", and associated logos (the "CIRIS marks") are marks of
CIRIS L3C. The code in this repository is licensed under the AGPL-3.0; the
marks are not. This split is deliberate and is where this project's
ethical-use commitment is enforceable (see README, "License and ethical use").

## Permitted without asking

- **Factual reference**: stating that your software uses, is built on, forks,
  or is compatible with CIRISHolon.
- **Unmodified redistribution**: conveying unmodified copies of this
  repository under its own name, with this policy intact.
- **Covenant-aligned deployments**: describing a deployment as running
  CIRISHolon where the deployment is consistent with the CIRIS Covenant and
  the code is unmodified or the modifications are conveyed under the AGPL.

## Not permitted

- Naming a product, service, deployment, or fork "CIRISHolon" or "CIRIS", or
  confusingly similar, in a way that implies origin from or endorsement by
  the maintainers — including and especially for deployments inconsistent
  with the CIRIS Covenant.
- Using the marks in a modified fork's name. Fork freely under the AGPL;
  choose your own name.
- Using the marks to advertise commercial support or services without a
  written agreement.

## The point, plainly

The AGPL guarantees everyone the code. The marks guarantee users that a thing
CALLED CIRISHolon is the ethical-use project the maintainers govern. An
unethical deployment of this code is an unlicensed use of the marks the
moment it wears the name.

organization.
