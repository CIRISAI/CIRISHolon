## What moved, and what governs it

`sigma_direct_t`'s mixed alpha-beta block walks the sparse `touched_kl` set in
**first-touch order** where it used to walk every `kl` ascending. `vrow[ib]` accumulates
over `kl`, so the sum is reassociated: no physics moves, the last bits do. Measured on
the shipped pair tables — 186/192 HCl energy knots moved, max **3.979e-12 Ha**, grid
0/192 different. That is 25x inside every declared uncertainty and inside R2's 1e-10
stake, so **no tolerance gate can see it and every identity gate can.**

**There is no size threshold.** Right mechanism, wrong axis — what governs is whether
the sparsity pattern's first-touch order differs from ascending, per system. Cl (9
determinants) moved, Br (18) did NOT, I (27) moved, at identical one-hole shape
(credit: elements3-heavy, whose re-banked dimer record is the measurement). So this
checklist enumerates moved/not-moved **per artifact by measurement, never by a rule.**

**And the general form, which is cheaper than either:** an artifact that will be compared
for IDENTITY should record the regime that produced it at the moment it is produced. A
budget field records one coordinate; the arithmetic is another; the honest answer is
closer to a build identity than to any single constant. Every hour this interval cost was
spent recovering a fact that was free to write down at generation time.
