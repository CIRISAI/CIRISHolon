## The full sum's measured exponent

S5 checks the full branch sum against the published `2^{0.396 t}`. TWO slopes are reported, because they are two different claims. BRANCHES is `log2(N_pred)` against `t` — the rate the published exponent is about. WALL is `log2(seconds)` against `t`, which is the branch rate PLUS the per-branch cost, and the per-branch cost grows with `t` because each branch evolves an affine state `n + t` wide. The last column is the difference: the overhead's own slope, which is where any gap lives.
