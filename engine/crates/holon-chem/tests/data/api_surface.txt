# Public items of `holon-chem` that NOTHING inside the library references.
#
# This file is deliberately NOT a .rs file and NOT under src/. The audit that reads it
# scans src/ for references, so an allowlist living there would make naming an item count
# as referencing it — an allowlist that launders its own entries out of the bucket it is
# exempting them from is not an allowlist. The sibling elements-referee lane learned that
# the hard way with its prose-field list; this is the same fix applied in advance.
#
# Every line is NAME <tab-or-spaces> WHY. A public item unreferenced inside the library is
# not automatically a defect — most of these are the crate's actual API — but each one has
# to be a decision. The shape this audit exists to catch is the opposite: a computation or
# a guard reachable only from a test, which looks alive and is not on any path that runs.
