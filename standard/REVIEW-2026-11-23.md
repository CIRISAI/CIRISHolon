# Review of the Holon Declaration, version 0: 2026-11-23

An adversarial review of the first draft, run before anything was committed, by a reviewer
briefed to break it: get false statements admitted, find true ones it could not express,
and check every claim in the document and the registry against the code. The first draft
is not in the repository; this file records what was wrong with it, so that the corrections
are not a quiet fix.

Verdict on the first draft: not fit to commit as "version 0, not frozen" yet.
The compiler's holes were tolerable in a version 0 that disclosed them. What was not: the
draft would have added statements to `OBJECT.md` that were false of the repository, and
its registry held admitted declarations that were false of the code.

## Not done, deliberately

- No tier or sector of `TIERS.md` is declared. The reviewer's condition for calling this
  version 0 in public is that the molecule tier and the hydrogen-bond sector are. That is
  owed (Section 6).
- The schema file is not run through a CDDL tool: phase A of the compiler is written to it
  by hand. The second pass found them out of step on five inputs (below).
- The uncommitted 3+1D gauge rung (branch `wip/holon-draw-2026-11-16`) adds a rung to the
  ladder. When it lands it must bring its declaration, or the gate will refuse the engine
  for drawing an undeclared rung, which is the gate working.
